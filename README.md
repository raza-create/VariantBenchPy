# VariantBenchPy

**A coverage-aware and bias-aware benchmarking framework for variant-effect predictors.**

Most benchmarks ask *"Which predictor has the highest AUROC?"*
VariantBenchPy asks the harder question: *"Is that ranking actually reliable and fair?"*

## Planned capabilities

1. Variant harmonization (VCF/CSV/TSV, HGVS, genomic coords, protein substitutions)
2. Predictor integration (AlphaMissense, EVE, CADD, REVEL, SIFT, PolyPhen-2, PLMs)
3. Coverage analysis
4. Complete-case bias analysis
5. Gene-level (equal-gene-weighted) evaluation
6. Missingness-bias diagnostics
7. Gene-clustered bootstrap confidence intervals
8. Ranking-stability analysis
9. Automatic sensitivity grids
10. One-command reproducible HTML/PDF report

## Status

Alpha — under active step-by-step construction.
